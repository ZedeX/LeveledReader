# LeveledReader - 分级阅读器

自托管分级阅读书籍管理器，内置Web阅读器。自动从分级阅读平台下载资源，提供沉浸式本地阅读体验。

> **免责声明**：本工具仅供个人教育使用。请尊重您使用的阅读平台的服务条款。请勿重新分发下载的内容。

---

## 在线阅读器

访问 [GitHub Pages](https://zedex.github.io/LeveledReader/) 即可直接使用在线阅读器。

### 功能特性

- **书架界面** — 按阅读级别（aa至Z2）浏览书籍，多行自适应布局
- **沉浸式阅读器** — 全屏阅读，自动播放音频
- **键盘导航** — 方向键翻页，空格键播放/暂停音频
- **后台预加载** — 自动预加载封面、页面图片和音频，优先级队列，断点续传
- **阅读进度** — 追踪每本书的阅读状态（未读/阅读中/已读完），进度存localStorage
- **成就系统** — 解锁里程碑（1-700本、级别完成），鲜艳配色徽章
- **访问控制** — 设备绑定8位密钥验证，30分钟时间窗口，离线算法
- **个性化** — 验证后输入名字，显示"XXX的Raz阅读器"

### 使用说明

1. 打开页面后，首先看到访问验证界面
2. 联系管理员获取8位密钥（密钥30分钟内有效）
3. 输入密钥验证后，输入你的名字
4. 开始阅读！按级别浏览书籍，点击封面打开阅读器
5. 阅读器中：左右箭头翻页，空格键播放/暂停音频

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| ← → | 上一页 / 下一页 |
| 空格 | 播放/暂停音频 |
| Esc | 关闭阅读器 |

## 技术实现

阅读器为纯前端单文件实现（`index.html`），无需服务器，可直接在浏览器中运行。

- 所有书籍数据内嵌在HTML中
- 验证逻辑在书籍数据之前加载，确保慢速网络也能先看到验证界面
- 资源通过Cache API + no-cors模式预加载
- 阅读进度和成就存储在localStorage
- Favicon以base64方式内嵌
